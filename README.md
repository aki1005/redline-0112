# 星屿咖啡厅活动指南

一个面向手机访问的线下动漫咖啡厅活动信息页，使用奶茶色、雾蓝和淡紫作为主视觉配色。

## 文件结构

- `index.html`：页面结构和所有占位内容。
- `style.css`：响应式布局、奶茶色视觉系统、原创 CSS 插画和动效。
- `script.js`：入场批次展开/收起和滚动进场动画。

## 本地运行

直接用浏览器打开 `index.html` 即可，也可以在项目目录运行任意静态文件服务器。

## 替换占位内容

在 `index.html` 中搜索地址、日期、批次时间和「敬请期待」等文字即可替换真实信息。每个 `.batch-card` 内的时间、状态、容量和提醒可独立修改；商品周边区块已经预留了 `#goods` 锚点，后续可直接替换 teaser 内容。

## 配色方案

当前实现采用奶茶色系：`#FFF8F1` 为背景主色，`#A76D56` 为咖啡棕强调色，`#F5B69C` 为暖桃辅助色，并以雾蓝 `#C6DCE6`、淡紫 `#D7C6DE` 区分信息卡片。备选方向可以将卡片色替换为粉蓝粉紫渐变，或改用更深的复古棕与抹茶绿来呈现日系咖啡馆风。
